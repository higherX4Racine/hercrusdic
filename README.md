# hercrusdic

<!-- badges: start -->

<!-- badges: end -->

Use Infinite Campus Data from Racine Unified School District

Since 2014-15, [Racine Unified](https://www.rusd.org) has used [Infinite
Campus](https://racinewi.infinitecampus.org/campus/racine.jsp) as its
student information system. This package provides an R interface to the
kinds of csv files that one can download from Infinite Campus’s web
interface.
