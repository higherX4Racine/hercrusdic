# Map grade levels to tiers of education

|              |            |
|--------------|------------|
| Grade Levels | Tier       |
| PK           | Preschool  |
| KG-5         | Elementary |
| 6-8          | Middle     |
| 9-12         | High       |

## Usage

``` r
TIERS_OF_EDUCATION
```

## Format

a tibble with 14 rows and two columns.

- Grade Level:

  `<fct>` equal to
  [GRADE_LEVELS](https://higherx4racine.github.io/hercrusdic/reference/GRADE_LEVELS.md)

- Tier:

  `<fct>` a factor with the four levels above
